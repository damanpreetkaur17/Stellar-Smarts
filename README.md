# 🚀 Stellar Smarts  

## 🌌 Overview  

**Stellar Smarts** is an interactive, visually immersive online quiz platform for space enthusiasts.  
Explore the wonders of the universe, test your knowledge, and learn fascinating cosmic facts—perfect for both beginners and advanced space learners!  

---

## 🌠 Features  

- **Three Quiz Levels:**  
  - 🌍 **Easy:** Relaxed pace for beginners  
  - ⏱ **Medium:** Timed questions to challenge recall  
  - 🚀 **Hard:** For space masters with advanced knowledge  

- **Interactive Flashcards:**  
  Flip through facts about planets, galaxies, black holes, and meteor showers.  

- **Dark Cosmic Theme:**  
  Glowing accents and immersive backgrounds for a space-inspired look.  

- **Expandable FAQs:**  
  Clickable and animated FAQ section for smooth user experience.  

- **Responsive Design:**  
  Works beautifully on desktops, tablets, and mobile devices.  

---

## 💻 Technologies Used  

- **Frontend:** HTML5, CSS3, JavaScript  
- **Animations:** CSS Grid, Flexbox, 3D Card Flips, Scroll Fade-in Effects  
- **Media:** Video background for immersive hero section
